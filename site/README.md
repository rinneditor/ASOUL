# A-SOUL Outfit Archive Site

## 中文

展示站使用原生 HTML、CSS 和 TypeScript，不依赖前端框架。页面从 `../asset/asoul_clothing_refs/manifest.json` 读取素材清单。

- `src/main.ts`: TypeScript 源码，也是页面逻辑的唯一编辑入口。
- `dist/main.js`: 编译后的浏览器脚本，由构建命令生成。
- `index.html`: 页面结构。
- `site.css`: 页面样式。

在本目录安装依赖并构建：

```sh
pnpm install
pnpm build
```

由于浏览器会读取仓库内的 JSON 文件，请通过本地 HTTP 服务打开仓库根目录，不要直接使用 `file://` 打开页面。

## English

The gallery uses native HTML, CSS, and TypeScript without a frontend framework. It reads asset data from `../asset/asoul_clothing_refs/manifest.json`.

- `src/main.ts`: TypeScript source and the single editable source of gallery behavior.
- `dist/main.js`: Compiled browser script generated by the build command.
- `index.html`: Page structure.
- `site.css`: Page styles.

Install dependencies and build from this directory:

```sh
pnpm install
pnpm build
```

Because the browser fetches the repository's JSON manifest, serve the repository root through a local HTTP server instead of opening the page with `file://`.
